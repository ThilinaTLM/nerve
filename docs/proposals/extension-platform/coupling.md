# Coupling inventory

Part of [Extension platform](README.md). Where the host knows a built-in extension today, and what replaces it. Migration steps and tests are left out.

| Layer     | Where                                                                                                                                   | Knows                                                                        | Replaced by                                                            |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| contracts | `domains/settings/settings.ts` (`atlassianProfiles`, `tavilyProfiles`, Kroki settings)                                                  | Typed accounts per product, Kroki URL                                        | Generic accounts store; manifest settings                              |
| contracts | `domains/tools/kroki.ts`, `domains/extensions/validator.ts`                                                                             | Kroki diagram types, URL validation                                          | Extension-local schema; settings field validators                      |
| tools     | `execution/web/web-search.ts`                                                                                                           | Tavily endpoint and key                                                      | Web extension method over `ctx.http`                                   |
| tools     | `catalog/definitions/core/web.tools.ts` (`web_search`), `result-projection/policies`, app `tool-result-parser.ts`                       | `web_search` as a core tool with its own view                                | Web extension `defineTool` bound to `web.search`; `links` display kind |
| tools     | `execution/web/html-to-markdown.worker.ts` (`confluence-storage` mode)                                                                  | Confluence macros                                                            | `confluenceStorageToMarkdown` in the Atlassian extension               |
| tools     | `execution/execution-context.ts` (`IntegrationExecutionContext`: `getApiKey`, `getProviderConfig`)                                      | Credential channel for Jira, Confluence, Tavily                              | `ctx.accounts` + credential injection in `ctx.http`                    |
| tools     | `policy/rule-sets/planning.json` (`toolGroups` `jira`, `confluence`)                                                                    | Removed direct-tool groups                                                   | Delete                                                                 |
| runtime   | `runtime/sdk-types.ts` (`QuickScriptContext`, `SdkEnvironment.jira()/confluence()/jiraFields()`, `report.pages`)                        | Every extension's context fields and caches                                  | `ctx`; per-run `session(ctx)`; generic `ctx.report`                    |
| runtime   | `runtime/sdk.ts` (Atlassian loaders, `nerve:atlassian-sdk` prelude)                                                                     | Atlassian wiring                                                             | Manifest `namespaces` and `prelude`                                    |
| runtime   | `runtime/files/artifacts.ts` (imports `extensions/atlassian/shared/raw-request.ts`)                                                     | Atlassian streaming sink                                                     | `ctx.http` `response: { artifact }`; `ctx.artifacts`                   |
| runtime   | `runtime/files/storage-helpers.ts`                                                                                                      | Confluence storage builders                                                  | Atlassian `prelude`                                                    |
| runtime   | `runtime/quick-script.ts` (`JIRA_/CONFLUENCE_UNAUTHORIZED` mapping)                                                                     | Atlassian error text                                                         | Host maps `401`/`403` on authenticated `ctx.http` requests             |
| runtime   | `runtime/method-samples.ts`, `index.ts` exports (`checkAtlassianConnection`, imagegen types)                                            | Samples and host exports                                                     | Move to the extension; types to `extension-api`                        |
| server    | `core-host/execution-accounts.ts`                                                                                                       | Account and secret resolution for Tavily and Atlassian                       | Generic resolution from manifest `requires` and `accounts`             |
| server    | `core-host/quick-script-availability.ts`                                                                                                | Settings keys, labels and fix texts of all four                              | Derived availability; optional `availability(ctx)`                     |
| server    | `core-host/extension-views.ts` (`hasCredential("atlassian" \| "tavily")`)                                                               | Credential kinds                                                             | Generic `hasSecret(kind, id)`                                          |
| server    | `app/bootstrap/create-conversation-core.ts`                                                                                             | Builds `kroki`, `web`, `imagegen`, `generateImage`, `getApiKey` map per call | Generic `ctx` built per extension through ports                        |
| server    | `create-runtime-services.ts`, `domains/auth/integration-health.service.ts`                                                              | Atlassian health check                                                       | Account kind `test(account, ctx)`                                      |
| server    | `domains/auth/auth-manager.ts` (`atlassian:`/`tavily:` prefixes, labels, env-var map)                                                   | Secret naming                                                                | `account:<kind>:<id>`; stale env entries removed                       |
| server    | `domains/image-generation/*` (imports imagegen types from quick-script)                                                                 | Backend contract location                                                    | `models.image` capability; types in `extension-api`                    |
| app       | `pages/extensions/AtlassianAccount*.svelte`, `TavilyAccount*.svelte`, `ExtensionDetail.svelte` kind branches                            | Account UI per kind                                                          | Generated account list and dialog                                      |
| app       | `pages/providers/provider-profiles.ts`, `ApiKeysSection.svelte`                                                                         | Secret id naming, prefix filters                                             | Account-owned secrets listing                                          |
| app       | `pages/extensions/extensions-view.ts` (`HELPER_NAMESPACES`)                                                                             | Helper namespaces `atlassian`, `storage`                                     | Namespace flag `helper: true`                                          |
| app       | `pages/tools/tool-settings.ts`, `tool-extension-links.ts`                                                                               | Tavily and Atlassian on the Tools page                                       | Generic per-extension link                                             |
| app       | `application/extensions/selected-accounts.svelte.ts`                                                                                    | `atlassian` and `search` slots                                               | `selectedAccount(extension, field)`                                    |
| app       | `presentation/integrations/atlassian-health.ts`; `presentation/context.svelte.ts` (`AtlassianLinkCapability`, no consumer since step 5) | Health badges, issue links                                                   | Generic health; delete the link capability                             |
| app       | `app/discover/guides/setup-content.ts`, `guides/state.svelte.ts`                                                                        | Atlassian and Tavily setup guides                                            | One generic extension setup guide                                      |
| manifests | `web/manifest.ts` `contributes.tools`                                                                                                   | Declared but consumed nowhere                                                | Manifest `tools` with `defineTool`                                     |

Extension code today imports `@nervekit/tools/execution` (`ToolExecutionError`, `withTimeoutSignal`, `searchTavily`, `downloadWebResource`, `isolatedHtmlToMarkdown`, MIME helpers), `@nervekit/contracts` (Kroki schemas) and `@nervekit/native` (`image` dimensions); all of these become `ctx` services or extension-local code.
