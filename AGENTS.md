- You are running on Nerve (`~/.nerve`). Avoid using the live home for debugging or test servers; preferably copy `~/.nerve` to `/tmp` and debug against that copy.
- Desktop and source-dev launchers default to `~/.nerve` and ports `3747`/`3748`. Keep Electron's active profile outside `NERVE_HOME` so full-home backup/migration remains safe; use explicit environment overrides for isolation.
- Prefer clean, simple architecture over compatibility layers and workaround shims.
- Keep shared API, event, policy, and storage schemas in `packages/contracts`; protocol types must remain transport-neutral.
- Use official shadcn-svelte components from `packages/ui-kit/src/lib/components/ui` and `@lucide/svelte` for icons. Style with shadcn theme tokens and Tailwind token utilities only, including `success`/`warning`/`info`. Use `destructive` for AA-readable red text/tints and `destructive-solid` + `destructive-solid-foreground` for opaque destructive fills. Avoid hard-coded colors, font sizes, spacing, and other one-off visual constants unless explicitly documented. Use monospace only for code, logs, and paths.
- Shared global CSS/tokens live in `packages/ui-kit/src/styles/`, with `app.css` as the entrypoint; apps should import it and add only app-specific partials. A class may be global only when consumed by 2+ components as a deliberate cross-component contract; otherwise keep it with the rendering component. `scripts/lib/style-policy.mjs` is the authoritative partial allowlist. See `packages/workbench-app/AGENTS.md` for the full styling model, escape hatches, and `:global` policy.
- Keep automated tests focused on important behavior; not everything needs automated coverage.
- Before completing code changes, run `pnpm fix && pnpm check && pnpm test` in a single Bash tool call. Fix failures, then rerun the full chain.
- To run the UI against an existing Nerve daemon, use `NERVE_API_TARGET=http://127.0.0.1:3747 pnpm dev:ui`.
- Use the `gh` CLI for GitHub operations.
