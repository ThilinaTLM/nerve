Build cache research

An illustrative evaluation of local and shared caching.

Start with a local cache. A shared cache is worth evaluating only after measuring duplicate work across machines.

Method

Compare cold builds, warm builds and invalidation behavior. Record the environment and use repeated measurements, not a single best-case run.

This example uses synthetic data; it does not claim real performance results.

Observations

Illustrative build times
Scenario Seconds
Cold build 90
Warm local cache 24
Shared cache hit 18

Cache keys must include toolchain versions and relevant inputs. A faster incorrect build is not a useful optimization.

Recommendation

Instrument local caching first, then revisit the shared-cache hypothesis using the same method.
