Offline report delivery

A small design proposal for portable document folders.

Status
Proposed
Owner
Documentation team

Ship HTML and versioned assets together. Readers should not need a build tool, account or network connection.

Problem

Remote dependencies make confidential reports less predictable. An offline folder makes the rendering contract explicit.

Design

The author prepares local assets, writes semantic HTML and validates the result.

The reader opens the HTML file directly. Source remains readable if JavaScript is disabled.

graph LR Prepare --> Author Author --> Validate Validate --> Deliver

Implementation

  1. Define the document vocabulary.
  2. Bundle local rendering dependencies.
  3. Validate references and structure.
  4. Test an isolated copy of the output.

Risks

HTML is active content. Validation is not a security sandbox and the document must not share a trusted app origin.

Out of scope

No editor, export pipeline or server-side publishing service.
