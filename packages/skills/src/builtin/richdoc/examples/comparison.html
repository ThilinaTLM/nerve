Storage options

An illustrative decision memo, not a benchmark.

Choose local storage for single-device use. Consider object storage when cross-device delivery becomes a requirement.

Comparison

Operational trade-offs
Criterion Local files Object storage
Offline access Native Requires a local copy
Operations Low complexity Credentials, network and lifecycle policy
Multi-device Manual sharing Shared endpoint

Trade-offs

  • Simple to inspect and back up
  • Works without network access
  • Sharing needs an explicit process
  • Accessible across devices
  • Central retention policy
  • More operational dependencies

Decision

Accepted for this example Start with local files and document the trigger for revisiting the decision.

Revisit when
Cross-device distribution becomes mandatory.
Evidence required
Usage, retention needs and confidentiality constraints.
