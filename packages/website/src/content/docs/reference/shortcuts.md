`Mod` means Command on macOS and Control on Windows/Linux. Shortcuts are currently fixed rather than user-remappable.

## Conversations and panes

| Action                | Shortcut          |
| --------------------- | ----------------- |
| New chat              | `Mod+N`           |
| New chat from project | `Mod+Shift+N`     |
| Search conversations  | `Mod+K`           |
| Close pane            | `Mod+W`           |
| Close other panes     | `Mod+Shift+W`     |
| Refresh pane          | `Mod+R`           |
| Previous / next pane  | `Mod+[` / `Mod+]` |
| Focus pane 1–9        | `Mod+1` … `Mod+9` |

## Composer

| Action                          | Shortcut           |
| ------------------------------- | ------------------ |
| Focus composer                  | `Escape`           |
| Send prompt                     | `Mod+Enter`        |
| Stop active run                 | `Mod+.`            |
| Toggle / cancel voice recording | `Alt+V` / `Escape` |
| Toggle coding/planning          | `Alt+M`            |
| Cycle permission                | `Alt+P`            |
| Cycle thinking                  | `Alt+T`            |

Plain `Enter` also submits from the composer when completion is not open. The explicit registered send shortcut is `Mod+Enter`.

## View

| Action     | Shortcut |
| ---------- | -------- |
| Zoom in    | `Mod+=`  |
| Zoom out   | `Mod+-`  |
| Reset zoom | `Mod+0`  |

Editable-field handling varies by command so browser/editor conventions are not accidentally overridden.
