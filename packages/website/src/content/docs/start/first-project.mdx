A project is a folder on your computer. Nerve keeps its conversations, launches, and notes with the project, and your code stays in the folder.

## Open a folder

<Steps>

1. Open the project switcher in the title bar and choose **Open folder**.
2. In the folder browser, pick a place on the left, or type a path in the path bar. Use the filter to narrow a long list, and **New folder** to create one.
3. Select your repository or workspace root and choose **Open**. If the folder is already a project, the button reads **Switch to project**.
4. Start a conversation.

</Steps>

You have two faster ways in:

- **Drag a folder onto the title bar** to open it as a project.
- On the desktop app, choose **System picker** in the project switcher to use your operating system's folder dialog.

The switcher also lists your recent projects, with a filter and activity markers for projects that have conversations waiting for you, active or failed runs, or running launches.

## Send a first prompt

Check that the composer shows the **Coding** profile and **Supervised** permission, then ask:

> Inspect this project and explain its architecture. Do not modify files.

You'll see the agent's text, any thinking the provider returns, and cards for each file read or search. Supervised permission lets safe reads through and asks before anything else.

## Good to know

- Opening a project gives the agent access to that folder, within the permission level you chose. A clean Git working tree makes review and recovery easier, but Git isn't required.
- Opening the same folder twice reuses its project. Switching projects doesn't close the others' conversations or launches.
- Removing a project from Nerve doesn't delete the folder.
- On a phone, projects live under the **Projects** tab. See [Find your way around](/guides/workbench/).
