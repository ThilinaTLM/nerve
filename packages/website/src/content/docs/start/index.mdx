This path takes you from a fresh install to a small, reviewed change made with Supervised permission, where Nerve asks before it acts.

## Your first run

<Steps>

1. **[Install Nerve](/start/install/).** Start the desktop app from npm. You need Node.js 24 or newer.
2. **[Connect a model](/start/providers/).** Sign in or add an API key, then pick a default model.
3. **[Open a project](/start/first-project/).** Choose a folder on your computer. Start with the Coding profile and Supervised permission.
4. **[Do your first task](/start/first-task/).** Inspect first, approve actions as they come up, then check the result in Git.

</Steps>
