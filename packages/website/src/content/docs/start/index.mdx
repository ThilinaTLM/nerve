Nerve is a local-first desktop coding harness for people who want an agent's work to stay visible and controllable. This path takes you from installation to a small, reviewed change with supervised permission.

## Your first run

<Steps>

1. **[Install Nerve](/start/install/).** Launch the desktop app from npm or a source checkout. You need Node.js 24 or newer.
2. **[Connect a model provider](/start/providers/).** Choose API-key or OAuth authentication, then select a default model.
3. **[Open a project](/start/first-project/).** Select a local directory and begin with Coding mode plus Supervised permission.
4. **[Complete a safe first task](/start/first-task/).** Inspect first, review approvals and diffs, run focused validation, and verify the final Git state yourself.

</Steps>
