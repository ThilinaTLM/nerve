Discover is a page inside Nerve that shows what's new, helps you finish setup, and offers a tour of the workbench. Open it from the Discover button in the title bar.

## What's on the page

- **What's new:** highlights of the current release, with a short archive of earlier ones.
- **Setup guides:** short coaches that take you to the right screen and point at the control to use.
- **Workbench tour:** a walk through conversations, the composer, approvals, panels, files, Git, launches, and Settings.
- **Tips:** short pointers to features you might miss.
- **Links:** documentation, release notes, and issue reporting.

## Setup guides

| Guide                       | What it does                                                   |
| --------------------------- | -------------------------------------------------------------- |
| Open a project              | Choose a folder to work in.                                    |
| Connect a model provider    | Sign in or add an API key.                                     |
| Enable voice input          | Connect a ChatGPT subscription so the microphone is available. |
| Configure scoped models     | Choose which models appear in the picker.                      |
| Configure agent defaults    | Set the default profile, permission, model, and thinking.      |
| Set up web search           | Add a Tavily key so agents can search the web.                 |
| Connect Jira and Confluence | Add an Atlassian profile and enable both tool groups.          |

Open a guide with **Start guide**. The tour needs an open project, so Nerve offers to open one first.

## Good to know

- Discover can open on its own after an update. Turn that off from the **Discover options** menu with **Open Discover after updates**.
- Nerve marks a guide done when its goal is already met, for example when a provider is connected. Use **Replay** to run one again. A revised guide can appear again.
- The title bar shows a badge on the Discover button when there are unread updates or unfinished setup.
