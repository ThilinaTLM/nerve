## Review changes

Nerve finds every Git repository in the project. Pick one from the repository chips to see its branch, change counts, and staged and unstaged files. Open a changed file to read its diff. If the current branch has a pull request, the panel links to it and its checks.

## Stage and unstage

1. Open a changed file to review its diff.
2. Stage or unstage it from its row. The **Staged** and **Unstaged** headings stage or unstage a whole group. Right-click a repository, group, folder, or file for actions on just that part.
3. To commit, ask the agent, or use the commit suggestion that appears when you have changes to commit.

Discarding changes asks for confirmation first.

## Switch branches

Create or switch branches from the branch control. When you're on a base branch with work to do, a suggestion offers to move the work to a new branch.

## Stash work

Stash from the **Staged** heading to save staged changes, or from **Unstaged** to save unstaged and untracked ones. Right-click a file or folder to stash just that path. When a repository has stashes, **Stashes (N)** opens a manager where you can apply a stash (keeping it) or drop it after confirming.

## Fetch, pull, and push

Fetch, pull, push, and sync run in the background, so you can keep working. The sync control shows progress and a **Stop** button when stopping is possible. Failures show up in [Notifications](/guides/notifications/) with **Retry** and **Dismiss**.

With several repositories, the **All repositories** menu offers **Fetch all**, **Pull all**, and **Switch all to base and pull**. The last one asks first and only fast-forwards. Git stops if local files would be overwritten.

## Good to know

- Stopping an operation doesn't undo steps that already finished.
- These panel actions are yours. The agent uses Git through shell commands, under your permission settings.
- Suggestion chips can offer to commit, move work off a base branch, or create a pull request. They only insert a prompt, so approvals still apply.
