The workbench has side panels, a tabbed center area for your work, and a title bar for projects and Discover. Drag the edges to resize panels.

## Use the panels

- **Conversations**, **Files**, **Launches**, and **Scratch Notes** start on the left.
- **Git Changes** and **Pull Requests** start on the right.

Drag a panel to another side or hide it. Nerve remembers your layout in this browser or window. Context usage lives in a popover beside the composer rather than in a panel.

## Work in tabs

Conversations, file previews, launch and command output, pull requests, Settings, and logs open as tabs in the center. Reorder tabs, or close the current tab, the ones beside it, or all others. A hidden conversation keeps streaming, so you can check another tab while it works.

## Switch projects

The title bar shows your recent projects. Open the project switcher to filter by name or folder, see which projects need you, and choose **Open folder** for a new one. See [Open a project](/start/first-project/).

The project menu has shortcuts for a new conversation, opening the project in an editor or terminal, pruning old conversations, and removing the project from Nerve. Removing a project doesn't delete its folder.

To find a conversation, use search (`Mod+K`) or the grouped list in the Conversations panel. See [Find and organize conversations](/guides/conversations/).

## Use a narrow window or a phone

Below 1024px, the side panels move into sheets. Below 640px, a phone layout takes over with three tabs: **Inbox** (what needs you), **Projects**, and **Activity**. Open a project from **Projects** to reach its conversations, files, Git changes, and pull requests as full screens. On phones, menus open as bottom sheets you can pull down to dismiss.

## Good to know

- Layout and tab choices are stored per browser. A different browser or cleared site data starts with defaults; your projects and conversations are unaffected.
- The bell in the header collects what needs you. See [Notifications and activity](/guides/notifications/).
- Take the tour from Discover. See [Discover and in-app guides](/start/learn-in-app/).
