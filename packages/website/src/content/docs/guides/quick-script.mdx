**Quick script** (`quick_script`) lets the agent write a short TypeScript script instead of spending a model turn on every request. One call can search Jira, read ten issues, build a spreadsheet, and publish a Confluence page, and only the script's printed output returns to the conversation.

## What a script can reach

The script runs in an isolated sandbox. It has no filesystem, network, Node APIs or `import`; it can only call the SDK that Nerve provides, and every call is checked against your permissions.

| Available                                         | What it gives the script                                                                                                                                | Set up in                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `files`, `artifacts`, `image`, `web.fetch`, `sdk` | Find, search, read, write and batch-edit project files; keep conversation files; resize or convert images; fetch a URL; discover the SDK                | Always present while Quick script is on                                            |
| `launches`                                        | List, start, restart, stop, and read logs of the project's launches by their Launches-panel label; create and edit definitions                          | Always present while Quick script is on; see [Launches](/guides/background-tasks/) |
| `configuration`, `extensions`                     | Read what is configured and in effect, check and reload configuration files, reload extensions. Used by the [Forge profile](/guides/configure-by-chat/) | Always present                                                                     |
| `mcp`                                             | Tools and resources of your [MCP servers](/integrations/mcp/)                                                                                           | Listed only while a server is on                                                   |
| `XLSX`, `Papa`, `docx`, `mammoth`                 | Read and write Excel, CSV, and Word documents                                                                                                           | Always present                                                                     |
| `PptxGenJS`, `JSZip`, `pptxText`                  | Build PowerPoint files, work with ZIP archives, extract slide text                                                                                      | Always present                                                                     |
| `jira`, `confluence`, `atlassian`, `storage`      | Issues, boards, sprints, pages, comments, attachments, and Confluence page builders                                                                     | [Atlassian extension](/integrations/extensions/#atlassian)                         |
| `search`                                          | Web search                                                                                                                                              | [Web Search extension](/integrations/extensions/#web-search)                       |
| `diagram`                                         | Render Mermaid, PlantUML, Graphviz and other diagrams to PNG                                                                                            | [Diagrams extension](/integrations/extensions/#diagrams)                           |
| `imagegen`                                        | Generate an image from a prompt                                                                                                                         | [Image generation extension](/integrations/extensions/#image-generation)           |

[Installed extensions](/guides/build-extensions/) can add namespaces of their own. The agent sees only the namespaces that are switched on and usable, and discovers methods itself with `sdk.list()`, `sdk.describe()`, `sdk.search()` and `sdk.docs()`. You never write the scripts; you describe the outcome.

## Turn it on

Quick script is on by default. To check or change it:

1. Open **Settings → Tools** and find **Quick script**. The row lists the namespaces that are currently available, or what to fix.
2. Switch on the extensions you want under **Settings → Extensions**. See [Extensions](/integrations/extensions/).
3. For one conversation, use the tools control beside the composer to turn Quick script on or off.

A project can set its own tool switches and extensions. Project files apply only after you trust them; see [Settings at a glance](/guides/settings/#items-you-review).

## Watch a script run

A Quick script tool card shows each SDK call as it happens, for example `jira.issues.get · jira:issue/APP-12`, so you can follow long scripts without waiting for the end. When the script finishes, the card shows its printed output, files it created, and a footer with the number of calls per product and the exit status.

- A script that fails, times out or is cancelled still returns a normal result, with a non-zero exit status.
- The default time limit is 120 seconds; the agent can ask for up to 600. A script is limited to 256 MiB of memory and 100,000 characters of code.
- Cancelling stops the script and its in-flight calls. Calls that already finished, such as a created issue, are not undone.
- Files a script writes are saved with the conversation, are copied when you fork it, and are removed with it. Attachment bytes and large files stay out of the model's context.

## Control what scripts may do

Permissions apply at two levels, so batching never widens what you allow.

1. **Before it runs.** Nerve reads the script and takes the highest risk among its calls: reading local files or documents is a read; reading Jira, Confluence, the web or diagrams is an external read; creating or editing issues and pages, or generating images, is an external write; deletes and raw non-GET requests are destructive. If Nerve cannot tell what a script does (for example, it builds method names dynamically), it counts as destructive. The approval card lists the operations and targets it found.
2. **While it runs.** Each call is checked again as an operation such as `jira.issues.create` on a target such as `jira:issue/APP-12`. A deny rule always holds. If you approved the script, it may make calls up to the risk you approved. If a rule allowed the script, any call that would need your approval is refused instead of asking midway.

What this means for each permission level:

- **Read-only** and **Planning** allow scripts that only read, including Jira, Confluence, web, and diagram reads. They block writes.
- **Supervised** asks before a script that reads or changes anything outside your project, such as Jira, the web, or an image provider. Scripts that only read project files and documents run without asking.
- **Autonomous** runs scripts without asking unless a rule blocks a call.

A script that starts or restarts a launch is rated as a Bash command. A script that calls an MCP tool is rated destructive, because Nerve can't know what the tool does; see [MCP servers](/integrations/mcp/#permissions).

Choose **Always allow** on an approval only when Nerve offers it; it is offered when Nerve can read every call in the script. You can also write rules for operations such as `jira.issues.*` in **Settings → Permissions**; see [Tools and approval policy](/developers/tools-policy/).

:::caution
Scripts can send data to Atlassian, a search provider, a Kroki server, or an image provider, using your configured accounts. Review the operations and targets before approving. The sandbox and permissions limit what a script can reach; they don't make remote content trustworthy.
:::

## Good to know

- Choose Quick script for integrations and document work, [Python execution](/integrations/python/) for general data scripting, and Bash for builds, Git and processes. Quick script isn't a way to run local commands.
- Quick script isn't replayed after a restart. A script that was running when Nerve stopped is marked as indeterminate instead of running again, because its calls may have partly completed.
- The direct `launch` tool is gone; launches are `launches.*` calls. Permission rules that named it were removed on upgrade, and a rule that also covered other tools but had matchers written for `launch` was disabled.
- The former direct Jira, Confluence, diagram, and image-generation tools are gone. Permission rules that named them were converted to Quick script operation rules on upgrade; a rule that couldn't be converted is disabled and reported.
