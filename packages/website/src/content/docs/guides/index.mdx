You don't need to learn every panel before you start. Begin with one conversation using the Coding profile and **Supervised** permission, then add what you need.

## The everyday loop

<Steps>

1. **Describe the outcome.** Use the [composer](/guides/composer/) to write a prompt, reference files, or add an image.
2. **Set how much the agent can do.** [Choose a profile and a permission level](/guides/agent-controls/).
3. **Stay involved.** Read the transcript and answer [approvals, questions, and plans](/guides/reviews/).
4. **Check the result.** [Review files](/guides/files-context-notes/), then look at the [Git changes](/guides/git/) and run your checks.
5. **Continue or branch.** Steer the agent, go back to an earlier point, or start a new conversation. The original stays intact.

</Steps>

## Terms you'll see

- **Agent:** the model-driven worker in a conversation. It can hand work to **sub-agents** such as Explore and Developer.
- **To-do:** the agent's checklist for its current work.
- **Launch:** a saved command for a server or watcher, with its own status and logs.
- **Background command:** a shell command the agent runs while you keep working.
- **Skill:** extra instructions for the agent. Enabling a skill doesn't grant new permissions.
