You do not need to learn every panel before starting. Begin with one conversation in **Supervised** mode, then add the workflows you need.

## The everyday loop

<Steps>

1. **Describe the outcome.** Use the [composer](/guides/composer/) to add a prompt, project paths, or an image.
2. **Keep the authority appropriate.** Choose [Coding or Planning mode and a permission level](/guides/agent-controls/).
3. **Stay involved.** Read the transcript and resolve [approvals, questions, and plan reviews](/guides/reviews/).
4. **Inspect the result.** [Edit or review files](/guides/files-context-notes/), inspect the Git diff, and run focused validation.
5. **Continue or branch.** Steer active work, return to an earlier history point, or start another conversation without losing the original record.

</Steps>

## Keep these concepts separate

- An **agent** performs work in a conversation. A lead can delegate to developer teammates or temporary Explore agents.
- A **to-do** is the agent's structured checklist for its current work.
- A **background task** supervises a long-running operating-system process such as a server or watcher.
- A **skill** supplies instructions. Enabling one does not grant extra tool permissions.

If you have not installed Nerve or connected a provider yet, use the [guided quickstart](/start/) first.
