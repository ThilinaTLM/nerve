Save the commands you run often as launches, start them from the Launches panel, and watch background commands the agent runs for you.

A **launch** is a saved definition: a name, a command, an optional working directory and port, and a run policy. Each start creates a new **run** of that launch, so the launch stays in place and earlier output stays available.

- **Single run** (default): starting a launch that is already running focuses the current run.
- **Concurrent runs**: starting again creates another run.

Agents can start, stop, restart, and read logs for your launches, but they can't create or edit them. A launch supervises a process; a to-do describes work inside a conversation.

## Create a launch

1. Open **Launches** and choose **Create launch**.
2. Enter a name and command, such as `Web dev` and `pnpm dev`.
3. Optionally choose a working directory and a TCP port. A blank directory uses the project root.
4. Choose **Single run** or **Concurrent runs**.
5. Save, then press play. Check the output and readiness before opening the service.

You can also edit, duplicate, and delete launches, or save an existing run as a launch. Editing changes future starts only. Give launches unique names so the agent can pick the right one.

## Pick up edited launch definitions

Launches live in `.nerve/launches/definitions.json` in the project. If you or a teammate edits the file outside Nerve, choose the **refresh** button in the Launches header to reload the definitions from disk.

## Watch background commands

When the agent runs a command in the background, or a foreground command runs longer than the wait you set, it appears under **Commands** in the activity island at the bottom of the transcript. Select a command to open its output, see its exit state and elapsed time, load earlier output, or stop it. Commands are separate from saved launches.

When a background command, or a launch the agent started, exits on its own, the agent is told and can pick up from there, so there's no need to ask it to poll.

## Good to know

- If a launch declares a port, starting it waits up to 30 seconds for the port to listen. If another program holds the port, Nerve shows which one; it never stops other programs for you.
- Quitting Nerve stops running launches and commands. Closing the window quits by default; if you turned on **Close to system tray** in **Settings → Workbench → Desktop**, closing hides the window and leaves them running.
- After a restart of the Nerve daemon, running processes are not recovered. Commands show as lost and launch runs disappear, but saved launches and their logs remain. Start the launch again when needed.
- Large output is summarized for the agent rather than pasted into the conversation.
