Every conversation keeps its full history. You can step back to an earlier point and try a different direction without losing what you had.

## Go back and branch

Open the history graph to see the conversation as a tree. Navigate to an earlier entry to continue from there. New work starts a branch, and the rest of the tree stays available.

## Edit an earlier prompt

Choose edit on one of your messages. Nerve goes back to just before it and puts the text in the composer. Change it and send it yourself, since Nerve never resends on its own.

## Make room in the context

Long conversations eventually fill the model's context. Nerve compacts them by summarizing older work and keeping recent messages.

- **Automatic:** compaction starts when context use reaches a threshold. Balanced (about 80%) is the default. Aggressive (70%) and Conservative (90%) are the other presets, and Custom lets you pick between 60% and 90%.
- **Manual:** use `/compact` or the compact button in the context popover beside the composer.

While compaction runs, a card previews the summary and sending is paused. If the summary can't be made, the existing context stays unchanged. Your stored history is never deleted. The figures it reports are estimates.

The context meter shows `?` right after compaction until the next response. Summaries lose detail, so keep lasting requirements in project instructions or repeat them.

## Recover from a failure

- **Retries:** Nerve retries temporary model errors automatically, up to three times.
- **Restart:** after Nerve restarts, an unfinished run is marked interrupted and isn't silently rerun. Read the last messages and tool results, then send a follow-up prompt to continue.
- **Background work:** commands the agent started don't survive a restart. Their status becomes `lost`. Saved launch definitions and their logs remain, so you can start them again.

## Good to know

- Background commands tell the agent when they finish, and sub-agents report back to the main agent.
- For stuck or lost processes, see [Process recovery](/troubleshooting/tasks-and-recovery/).
