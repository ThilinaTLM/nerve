The desktop layout has a conversation/task dock, a tabbed center workspace, and a secondary dock. Drag resize handles to allocate space. Panel views can move among left, right, and bottom docks or be hidden; Nerve repairs obsolete saved layouts after upgrades. The title-bar Help button opens the built-in Guides catalog, including a full Workbench tour.

## Dock views

Six views can live in docks:

- **Conversations** and **Tasks** begin on the left.
- **Git**, **Pull Requests**, **Context**, and **Notes** begin on the right.

Notes are a project panel, not a center tab. Panels intentionally adapt to their current width rather than assuming a particular dock.

## Center tabs

The center workspace opens conversations, pending conversations, task output, file previews, pull request details, Settings, authentication, and Nerve logs. Reorder tabs or close the current tab, tabs to either side, or all others. Conversations stay mounted when hidden so live transcript state remains stable.

## Find work

Use the project picker to search recent projects and directory paths. Conversation search is a separate modal and can filter a project's conversations. The navigator initially bounds long lists and exposes more entries on demand.

## Compact layouts

Below 1024px, Nerve switches to a single center column. Left dock views move into a left sheet; right and bottom views share a second sheet. Below 640px, controls use phone-oriented density. This is a functional layout, not merely a scaled desktop screenshot.

Layout and active-tab preferences are browser-local. A different browser profile or cleared site storage starts with defaults even though server-side projects and conversations remain.

## Built-in tour

Choose **Help → Guides → Work through the Workbench** for an interactive tour of the composer, review controls, panels, files, Git, tasks, providers, Settings, and status. The tour needs an active project and can be replayed after completion.
