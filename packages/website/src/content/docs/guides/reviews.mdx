When the agent needs you, it shows a card in the transcript beside the work that caused it. The composer stays disabled until you answer, so a new prompt can't skip the decision.

## Approve an action

With Supervised permission, the agent pauses before commands, file changes, and network use. Each card shows the tool, its arguments, and any preview. Approve only what you understand. A denied or failed action stays in the transcript.

To avoid repeated prompts for a rule Nerve can describe, choose **Always in project** or **Always for user**. Rules saved to a project need your trust before they apply, and editing the project's rules outside Nerve withdraws that trust. Python runs and destructive, secret, or deployment actions can only be approved once. Autonomous permission skips approvals for allowed actions but still honors blocks, and Read-only denies instead of asking.

Permissions are checked again right before an action runs, so approving never overrides a block.

## Answer a question

A question card can hold one or several questions, each with options, a recommendation, and a free-text answer. With a single question, choosing an option sends it right away. With several, choose your answers, add detail where you want, then send them together.

Use **Add detail** to explain an option, or reply in your own words. The reply box supports `@` references and image paste, and you can dictate with the microphone. Drafts survive switching conversations, and answered questions stay in the transcript with your choice marked. Dismiss a question that no longer matters.

## Review a plan

In the Planning profile, the agent finishes by presenting a plan for you to read. **Accept & Implement** starts the work in the same conversation. Its menu has more choices:

- **Compact & implement** starts with a smaller context.
- **Accept in new chat** begins the implementation in a fresh conversation.
- **Choose model & …** lets you pick the model for any of these.

Rejecting the plan keeps Planning, and the agent waits for your next prompt. Before accepting, check the files affected, how it will be validated, and any migration or security impact. A plan is a proposal, not finished work.

## Good to know

- If the profile you're switching to has requirements, the review shows them. Choices that don't fit are flagged rather than silently changed.
- If a security configuration is invalid, the action waits as **configuration-blocked** with **Retry** and **Cancel**, not Approve.
- Long output is stored as linked files rather than pasted into the conversation.
